# Changelog

## v1.0.0 Experimental

First public experimental release of ASUS FanPilot Dial.

- Run a cooling curve or fixed PWM while G-Helper manages laptop performance modes.
- View individual fan RPMs, CPU temperature and NVIDIA GPU temperature when available.
- Edit paired fan curves with exact point entry, temperature preview, per-profile drafts and named presets.
- Open Advanced tuning for sensor sources, response delays, RPM calibration and draft reset.
- Use tray controls, a configurable global shortcut and optional start with Windows.
- Restore firmware control through the dashboard, curve workspace or tray. The app reports an unconfirmed reset and provides a retry action.
- Use the included offline demo with simulated fans to explore the interface.
